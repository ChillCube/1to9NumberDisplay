# 1to9NumberDisplay

A godot class that displays a number from 1 to 9

## Installation

Make sure to download the ChillCube Developer tools to use this addon: https://github.com/ChillCube/ChillCube-Developer-Tools.git

### Linux
To add this to your project, copy paste these commands into terminal at the root of your project:
```bash
clone-gd-addon https://github.com/ChillCube/1to9NumberDisplay.git
```

## Documentation
You can find the documentation at: https://github.com/ChillCube/1to9NumberDisplay/blob/main/DOCUMENTATION.md

## Deinstallation
### Linux
Run this in the root of your godot project:
```bash
remove-gd-addon 1to9NumberDisplay
```

## For Developers
### Push Changes
Run this at the root of your directory to push changes to any addons you have:
```bash
push-all-addons
```
