# 1to9NumberDisplay

A godot class that displays a number from 1 to 9

## Installation

Make sure to download the ChillCube Developer tools: https://github.com/ChillCube/ChillCube-Developer-Tools.git

### Using the Godot Plugin
Enable the **ChillCube Tools** plugin, then paste the repo URL into the Clone tab.

### Linux / CLI
```bash
clone-gd-addon https://github.com/ChillCube/1to9NumberDisplay.git
```

## Documentation
https://github.com/ChillCube/1to9NumberDisplay/blob/main/DOCUMENTATION.md

## Deinstallation
Use the CC Tools panel in Godot, or run:
```bash
remove-gd-addon 1to9NumberDisplay
```

## For Developers
```bash
push-all-addons
```
